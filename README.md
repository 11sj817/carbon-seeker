# 碳寻 · Carbon Seeker

企业碳减排管理的碳应用平台 —— **交互式项目展示站**。
把《碳寻计划书》《碳寻省赛 PPT》与省赛获奖名单里的事实，做成一个可以在浏览器里真的算一遍的网站：
个人碳足迹、企业碳账本（Scope 1/2/3）、绿色积分兑换、两侧对照看板，外加项目资料与团队成果。

- 在线地址：https://11sj817.github.io/carbon-seeker/
- 单文件产物：`dist/index.html`（拖进浏览器就能用，不需要服务器）
- 全部计算在本地完成，**没有后端、没有网络请求、没有埋点**；输入只写在浏览器 localStorage。

## 这个站和一份 PPT 的区别

| 常见做法 | 这里的做法 |
| --- | --- |
| 排放量写成一段文字 | 34 项因子 + 公式，改任何输入结果实时变 |
| 对标结论写死“优于行业” | 用当前产值与排放实算强度，再和行业示意基准比 |
| 减碳建议是标语 | 每条形如“每月 X km 改乘地铁 → 省 Y kg”，按可减量排序 |
| 积分是营销道具 | 1 kg 减排 = 10 分，兑换时固碳量逐项可算 |
| 数据来源含糊 | 「数据与方法」页逐条列出单位、系数与出处，并写清边界 |

## 开发与构建

```bash
# 计算内核、推广经济模型与图表生成器：28 个用例
node --test tests/calc.test.js tests/econ.test.js

# 合成单文件：dist/index.html + docs/index.html（GitHub Pages 目录）
python build.py

# 只校验产物是否与源码一致（发布前 / CI 用）
python build.py --check
```

真实浏览器验收（可选，需先起一个开了 CDP 的 Edge）：

```bash
msedge --headless=new --remote-debugging-port=9333 --user-data-dir=<临时目录> about:blank
node qa/cdp-check.mjs 9333 "file:///<仓库>/dist/index.html" qa
```

`qa/browser-check.json` 记录每个视图的字数、卡片数、图表数、横向溢出、JS 异常，以及
“改输入 → KPI 与环形图同步变化 / 焦点保留 / 增删行 / 深色主题 / 导出文件内容”的实测结果，
截图见 `qa/shot-*.png`。

## 数据与方法

排放因子来自生态环境部公开口径、《省级温室气体清单编制指南（试行）》、
DEFRA 2023、Poore & Nemecek (2018) 等公开资料，逐条列在 `src/core/factors.js` 的 `src` 字段，
并在站点「数据与方法」页展示。**行业强度基准是示意值**，个人侧参照值（2.6 tCO₂e/人·年）是
按居民生活消费折算的近似值，两者都只用于同口径相对比较。

详见 [DATA_SOURCES.md](DATA_SOURCES.md)。

## 边界

本站是创新创业项目展示与教学演示，不提供碳核查、碳交易或认证服务；
所有减排量、固碳量均为估算，不构成可交易的核证减排量（CCER）。对外披露请以第三方核查报告为准。

## 与 DAC Workbench 的关系

工程范式沿用同一套：`src/` 分模块 → `build.py` 合成单文件 → `docs/` 走 GitHub Pages →
`node --test` 校验内核 → CDP 真机验收 → 构建摘要进产物。界面同样是“左侧模块栏 + 顶部状态头 +
证据化内容面板”的工作台骨架，只是把冷色研究台换成了绿色碳主题，并把内容从数据科学换成碳管理。
